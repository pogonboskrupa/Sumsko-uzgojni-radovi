## 🚀 Pokretanje lokalno

Samo otvori `index.html` u browseru – ne treba server ni instalacija.

---

## 🌐 GitHub Pages

1. Idi na **Settings → Pages**
2. Source: `Deploy from a branch`
3. Branch: `main` / `root`
4. Sačuvaj → stranica je dostupna na:  
   `https://[tvoj-username].github.io/[naziv-repo]/`

---

## 📋 Funkcionalnosti

- **Čekiranje** – svaki odjel/stavka može biti označena kao izvršena (red se oboji zeleno)
- **Progress bar** – vizualno praćenje procenta izvršenja
- **Unos podataka** – narandžaste kolone za unos vrijednosti iduće godine
- **Promjena godine** – jedan klik na vrhu dokumenta
- **Pro štampanje** – A4 landscape (sječa) / A4 portrait (uzgojni radovi), skriveni UI elementi, profesionalne sekcije, footer na svakoj stranici
- **CSV export** – preuzimanje tabele sječe sa statusom

---

## 🖨 Upute za štampanje

1. Otvori dokument u Chromu ili Firefoxu
2. Klikni dugme **🖨 Štampaj**
3. Postavke: **A4**, **Landscape** (sječa) / **Portrait** (uzgojni), uključi **Background graphics**
4. Svi tabovi se automatski štampaju, dugmad i interaktivni elementi se skrivaju

---

## 📅 Template za iduću godinu

1. Otvori HTML fajl
2. Promijeni godinu u polju na vrhu (default: 2027)
3. Popuni narandžaste kolone sa novim podacima
4. Opciono: kopiraj fajl i preimenuj u `sjeca_krupa_2027.html`
